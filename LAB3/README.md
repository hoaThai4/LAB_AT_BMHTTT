### Bước 1 – Tạo máy ảo
- Tạo máy ảo Windows 11 25H2 x64 trên VMware Workstation.
- Cấu hình: 2 vCPU, 6 GB RAM, ổ đĩa 64 GB.
- Cấu hình Network Adapter ở chế độ Host-only.
- Kiểm tra phiên bản Windows 11 và Windows Update.

### Bước 2 – Tạo cấu trúc thư mục
Tạo thư mục bài Lab tại:
C:\LAB3

Gồm các thư mục:
- Evidence
- Tools
- Downloads
- Assets

### Bước 3 – Chuẩn bị môi trường
- Mở Windows PowerShell với quyền Administrator.
- Chuẩn bị thư mục lưu công cụ, dữ liệu và bằng chứng thực hiện Lab.

### Bước 4 – Tạo thư mục Evidence
- Tạo thư mục C:\LAB3\Evidence để lưu kết quả và ảnh chụp trong quá trình thực hiện.
- Chuẩn bị file start_time.txt để ghi nhận thời gian bắt đầu Lab.

## 3. Kết quả
- Máy ảo Windows 11 đã được thiết lập.
- Network được cấu hình Host-only.
- Cấu trúc thư mục LAB3 đã được tạo.
- Đã chuẩn bị thư mục Evidence để lưu bằng chứng.

## 4. Lưu ý
- Thực hiện Lab trên máy ảo.

- Khi thực hiện các bước tiếp theo, lưu đầy đủ bằng chứng vào thư mục Evidence.
